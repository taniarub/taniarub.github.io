# Window Installation Company Website

A one-page responsive website for a company that sells and installs windows in Belarus.

## Features

- **Header** with company name and advantages
- **Calculator** for estimating window costs based on type and dimensions
- **Product catalog** showcasing different window types
- **Client reviews** section
- **Contact form** with social media links
- Responsive design that works well on all devices

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser

No server or build steps are required, as this is a static HTML website.

## Image Placeholders

The website is designed with placeholder images for:
- Window products (plastic windows, aluminum windows, double-glazed units)
- Client avatars

For a production site, replace the placeholder images in the `/images` directory with actual product photos and client images.

## Customization

### Changing Contact Information
Edit the contact information in the "Contacts" section of `index.html` to include the actual company details.

### Modifying Price Calculation
To adjust the pricing logic for the window calculator, edit the calculation in `script.js` within the calculator form submit handler.

### Updating Client Reviews
Replace the placeholder client reviews in the "Reviews" section of `index.html` with actual client testimonials.

## Technologies Used

- HTML5
- CSS3 (with responsive design)
- JavaScript (ES6)
- Font Awesome icons
